# Aegis UX 项目上下文

Aegis 是由内嵌 Go AgentCore 驱动的本地任务控制台。操作者在这里发布目标、观察多 Agent 执行、处理审批与异常、验收结果，并追溯 Issue、Session 和工作区证据；文件与命令工具在任务专属 Docker 容器中执行。

主要角色是任务操作者、人工审核者、Agent/组织管理员和运行维护者；同一个人常同时承担多个角色。界面必须按“发起目标 → 观察执行 → 处理例外 → 验收结果”组织，而不是按后端对象堆叠菜单。

约束：React 19、Vite、Tailwind CSS v4、shadcn Base Nova、Lucide；支持浅色/深色和 320px–1440px+。视觉要求是专业、克制、高信息密度、低圆角，不使用装饰性渐变、大面积阴影或重复卡片。
