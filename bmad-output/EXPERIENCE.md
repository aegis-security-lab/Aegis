## 核心体验

Aegis 的主循环是：发布目标 → 观察执行 → 处理例外 → 验收结果 → 追溯证据。默认首页首先暴露需要人工介入的审批、阻塞和失败；普通历史退到第二层。

## 用户旅程

### 1. 发布并监控任务

`概览/任务 → 新建任务 → 定义目标和边界 → 发布 → 任务详情 → 计划树/Session → 交付文件`

- 目标：2 分钟内发布结构清晰的任务，并能在一次跳转内看到是否推进。
- 分支：负责人或环境不可用时在字段旁说明；发布失败保留输入并聚焦错误；发布成功直接进入任务详情。
- 任务详情把状态、负责人、预算、计划树入口放在首屏；定义与历史在后。

### 2. 通过管家形成任务

`管家 → 选择/新建会话 → 描述需求 → 管家处理 → 关联任务 → 查看任务`

- 桌面固定显示会话栏；移动先显示会话列表，进入会话后提供返回。
- 会话头始终显示处理状态和关联任务；发送失败恢复草稿。
- 加载、空会话、读取失败必须可区分，不能都表现为“没有消息”。

### 3. 处理审批与阻塞

`顶栏/概览待处理 → 审批或 Issue → 阅读请求、风险、证据 → 批准/拒绝/恢复 → 下一项`

- 待审批数量在顶栏与概览均可点击；审批不藏在设置。
- 决策动作与证据就近；拒绝/验收意见使用字段级校验；处理中显示 Spinner 并阻止重复提交。

### 4. 定位 Issue 并干预

`任务/概览 → 计划树 → 搜索/状态筛选 → 展开层级 → Issue 详情 → 评论/返工/恢复`

- 搜索、状态筛选和展开控制位于同一工具栏。
- 失败原因旁提供允许的恢复动作；删除等低频破坏操作进入更多菜单。

### 5. 管理员工与能力

`员工工作台 → 员工管理 → 人才模板/组织岗位 → 技能与知识库 → 权限 → 保存`

- “员工工作台”是观察和协作入口；“员工管理”是配置入口。
- 人才模板、岗位、技能、知识库按依赖关系就近链接，不要求用户记忆模块路径。

### 6. 配置运行环境

`设置 → Runtime/模型/工作区/策略/Web 搜索 → 就近检测 → 保存`

- 所有设置使用真实页面而非巨型弹窗；分类保持在 URL 可恢复的方向上迭代。
- Runtime 路径旁显示探测结果；模型认证旁显示连接结果；有改动时显示未保存状态。

## 屏幕与状态清单

| 屏幕   | 默认/焦点                         | Loading           | Empty              | Error/Recovery        | Success              |
| ------ | --------------------------------- | ----------------- | ------------------ | --------------------- | -------------------- |
| 概览   | 可钻取摘要 + 待处理 + 最近任务    | 保留摘要骨架      | 解释并“发布任务”   | 顶栏 live 状态 + 重试 | 实时更新数值         |
| 任务   | 搜索/状态筛选 + 紧凑行            | 行骨架            | 发布第一个任务     | 就近提示，保留筛选    | 新执行后进入详情     |
| 计划树 | 搜索、状态、层级                  | 树骨架            | 清除筛选           | 重试或返回任务        | 树状态实时更新       |
| 管家   | 会话栏 + 状态头 + 消息 + Composer | 列表/消息各自加载 | 明确可输入的空会话 | 保留草稿并重试        | 关联任务入口可见     |
| 审批   | 待办优先                          | 当前动作 Spinner  | 队列为空说明       | 字段级错误 + 重试     | 自动刷新并聚焦下一项 |
| 设置   | 分组表单 + 保存                   | 按钮加载          | N/A                | 字段旁错误            | 显示保存时间/版本    |

## 交互与动画

| 交互           | 行为                       | 时长      | Reduced motion |
| -------------- | -------------------------- | --------- | -------------- |
| Hover/focus    | 颜色、边界、焦点环         | 120–150ms | 即时           |
| Button press   | `scale(.98)`               | 100ms     | 取消缩放       |
| Popover/Dialog | 从触发点淡入 + 0.95 缩放   | 150–200ms | 即时显示       |
| 状态更新       | 数字和文本直接替换；不闪烁 | ≤150ms    | 相同           |

## 验证任务

正式发布前用文本树测试四项：找到待审批、查看员工当前工作、查看任务时间线、配置 Web 搜索。目标首次成功率 ≥70%，路径不超过最优路径的 1.5 倍。
